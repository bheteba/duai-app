# دوائي — نسخة مصر 🇪🇬

تم ضبط المشروع ليكون موجهاً للسوق المصري من البداية:

- الدولة الافتراضية: مصر (EG).
- العملة في أي خدمات مستقبلية: الجنيه المصري (EGP).
- رقم الهاتف: تنسيق مصري +20.
- بيانات المستخدم تشمل المحافظة/المدينة والمنطقة.
- أمثلة المناطق داخل التطبيق تستخدم القاهرة.
- لا يتم عرض عنوان المنزل؛ يستخدم التطبيق منطقة تقريبية أو نقطة استلام عامة.
- قاعدة البيانات تحتوي على حالة مراجعة الدواء `pending/approved/rejected` وحقول تساعد على منع نشر دواء غير موثوق.

## مهم قانونياً

النسخة الحالية ليست تصريحاً قانونياً لتبادل الأدوية بين الأفراد. هيئة الدواء المصرية هي الجهة المنظمة لتداول ومراقبة المستحضرات الصيدلية، وتعرض تشريعات وضوابط متعددة مرتبطة بالمستحضرات والصيدلة. لذلك صُمم الـBackend بحيث يمكن وضع مراجعة/حظر قبل النشر، ولن نفترض أن كل دواء مسموح بتبادله بين الأفراد.

المصدر الرسمي: https://www.edaegypt.gov.eg/ar/المرجع-التنظيمي-لهيئة-الدواء-المصرية/

## المستخدمان الحقيقيان

حالياً تسجيل الدخول في النسخة يستخدم البريد الإلكتروني وكلمة المرور عبر Supabase. يمكن إضافة تسجيل الدخول برقم الهاتف المصري (+20) لاحقاً بعد إعداد مزود SMS في Supabase.

## تشغيل Backend

1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor.
3. نفّذ ملف `supabase_schema.sql` كاملاً.
4. شغّل Flutter مع:

```bash
flutter pub get
flutter run --dart-define=SUPABASE_URL=YOUR_URL --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

لا تضع Service Role Key داخل تطبيق الهاتف.
