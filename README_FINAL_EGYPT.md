# دوائي 🇪🇬 — النسخة النهائية المبدئية للتطوير

هذه النسخة مبنية لتطبيق مصري RTL، وتستخدم Supabase كـ Backend وقاعدة بيانات.

## ما تم تجهيزه
- واجهة عربية RTL وهوية «دوائي».
- تسجيل وإنشاء حساب عبر Supabase Auth (البريد/كلمة المرور في النسخة الحالية).
- دعم بيانات الهاتف المصري والمحافظة/المدينة/المنطقة.
- قاعدة بيانات Profiles + Medicines + Exchange Requests + Reports.
- سياسات RLS للحماية.
- منع ظهور الدواء للمستخدمين قبل حالة approved، ومنع ظهور الدواء المنتهي في القوائم العامة.
- تصميم مرجعي نهائي في `assets/duai_final_design_storyboard.png`.

## تشغيل المشروع
1. أنشئ مشروع Supabase.
2. افتح SQL Editor والصق كامل ملف `supabase_schema.sql`.
3. شغّل التطبيق بقيم:
   `--dart-define=SUPABASE_URL=...`
   `--dart-define=SUPABASE_PUBLISHABLE_KEY=...`
4. فعّل Email Auth في Supabase لاختبار أول مستخدمين.
5. لاحقًا فعّل Phone Auth واربط مزود SMS المعتمد لمصر.

## OTP وتعدد مزودي SMS
التطبيق لا يحتوي مفاتيح مزودي SMS داخل الهاتف. طبقة OTP يجب أن تكون على Backend/Edge Function، وتدعم fallback بين المزودين. أضف مفاتيح CEQUENS/Infobip/Twilio أو مزود مصري من لوحة الخادم فقط.

## قبل الإطلاق العام
- مراجعة قانونية وتنظيمية مصرية لتداول/مشاركة المستحضرات الدوائية بين الأفراد.
- قائمة أدوية محظورة/مقيدة قابلة للتحديث من لوحة الإدارة.
- مراجعة الصور والصلاحية ومصدر العبوة.
- تخزين الصور في Supabase Storage بسياسات وصول مناسبة.
- لوحة Admin لمراجعة الأدوية والبلاغات والمستخدمين.
- إشعارات Push ومحادثة داخلية ونقاط استلام عامة.
