# دوائي — Flutter Android + iPhone

هذا المشروع يحول Prototype «دوائي» إلى تطبيق Flutter متعدد المنصات.

## التشغيل
ثبت Flutter 3.x ثم:
```bash
flutter create .
flutter pub get
flutter run
```

### Android
```bash
flutter build apk --release
```
ينتج APK جاهزًا للتثبيت.

### iPhone
على macOS مع Xcode:
```bash
flutter build ios --release
```
ثم افتح مشروع `ios/Runner.xcworkspace` في Xcode لإعداد Signing ورفع التطبيق إلى App Store/TestFlight.

## ما يعمل في النسخة
- واجهة عربية RTL.
- الرئيسية والبحث والإضافة والطلبات والحساب.
- إضافة صورة من الكاميرا/المعرض.
- بيانات الدواء والتحقق والمعاينة والنشر.
- المطابقة الذكية كتجربة UI.
- طلب وقبول التبادل.
- تحديد نقطة وموعد الاستلام.
- رمز استلام وإتمام العملية والتقييم.

## ما يلزم قبل الإطلاق التجاري
هذه النسخة Client/MVP. لتصبح خدمة حقيقية متعددة المستخدمين يلزم Backend وقاعدة بيانات وOTP وإشعارات وتخزين صور ولوحة إدارة، إضافة إلى تحديد الدولة المستهدفة وقواعد الأدوية المسموح بتداولها ومراجعتها قانونيًا وصيدلانيًا.
